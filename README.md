# OOP Bank Account System

## Overview
This project is a simple banking system developed using Python and Pandas. It demonstrates Object-Oriented Programming (OOP) concepts such as classes, objects, constructors, and methods while maintaining transaction history and performing CSV data analysis.

## Features
- Create a bank account
- Deposit money
- Withdraw money
- View account balance
- Store transaction history
- Save transactions to a CSV file
- Analyze transaction data using Pandas

## Technologies Used
- Python
- Pandas
- CSV Files

## Project Structure

OOP_Bank_Account/
│
├── bank.py

## How to Run

1. Install Pandas

```bash
pip install pandas
```

2. Run the program

```bash
python bank.py
```
